<!-- ── INTRODUCTION ───────────────────────────────────────── -->

Hi, I'm **Ananya** — a Computer Science student specialising in **AI & Data Science**, with a focus on agents, forecasting, and decision support.

I'm drawn to the space where rigorous engineering meets genuine curiosity: building systems that learn, reason, and make data actually useful. My work spans machine learning pipelines, applied research, and the occasional side project that starts with *"what if…"* and ends several rabbit-holes later.

When I'm not writing code I'm usually reading papers, sketching out ideas, or finding out the hard way that debugging at midnight is not my best decision-making context.

> *Principle: evidence before claims.*

Open to **SDE and AI/ML internships** and research collaborations.

<!-- ── WHAT INTERESTS ME ──────────────────────────────────── -->

## 🔍 &nbsp;What interests me

```
AI Agents             →  LangGraph, critic loops, multi-step reasoning
Forecasting           →  time-series models, early-warning systems
Data Engineering      →  pipelines, warehouses, feature stores
Applied Research      →  turning papers into runnable experiments
Software Development  →  clean, testable, maintainable code
```

I care about the full journey: from a raw idea or messy dataset through to something that actually works reliably in the real world. I'm especially interested in how AI systems fail and what that reveals about the assumptions baked into them.

## 🛠 &nbsp;How I build

<table>
<tr>
<td width="65%" valign="top">

I try to understand a problem before reaching for a solution. That usually means spending longer than feels comfortable reading documentation, tracing through someone else's code, or just drawing boxes on paper.

I prefer writing code that a future version of me can read without wanting to rewrite it entirely — which means comments, tests, and not being clever when clear will do.

I think the best projects are built incrementally, with room to be wrong early and often.

## 📌 &nbsp;Selected projects

`Python` &nbsp;`LangGraph` &nbsp;`FastAPI`

`Python` &nbsp;`Random Forest`

</td>
