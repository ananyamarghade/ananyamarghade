<!-- HOW I BUILD -->

<img
  src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=20&pause=99999&color=9EB9A4&center=false&vCenter=true&repeat=false&width=420&height=45&lines=%F0%9F%9B%A0+How+I+build"
  alt="How I build"
/>

I try to understand a problem before reaching for a solution - which usually means spending longer than feels comfortable reading documentation, tracing through someone else's code, or just drawing boxes on paper.

I prefer writing code that a future version of me can read without wanting to rewrite it entirely. That means comments, tests, and not being clever when clear will do.

I think the best projects are built incrementally, with room to be wrong early and often.
