## 🔍 &nbsp;What interests me

```
AI Engineering        →  model training, fine-tuning, deployment
Data Systems          →  pipelines, warehouses, feature stores
Applied Research      →  turning papers into runnable experiments
Software Development  →  clean, testable, maintainable code
```

I care about the full journey: from a raw idea or messy dataset through to something that actually works reliably in the real world. I'm especially interested in how AI systems fail and what that reveals about the assumptions baked into them.

<!-- ── HOW I BUILD ─────────────────────────────────────────── -->

## 🛠 &nbsp;How I build

<table>
<tr>
<td width="65%" valign="top">

I try to understand a problem before reaching for a solution. That usually means spending longer than feels comfortable reading documentation, tracing through someone else's code, or just drawing boxes on paper.

I prefer writing code that a future version of me can read without wanting to rewrite it entirely — which means comments, tests, and not being clever when clear will do.

I think the best projects are built incrementally, with room to be wrong early and often.
